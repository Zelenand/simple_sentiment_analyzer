## Использование

### Анализ одной строки

```bash
python -m sentiment_ru "Мне очень понравился этот фильм!"
```

Пример результата:

```text
Текст: Мне очень понравился этот фильм!
Положительная: 1.000
Отрицательная: 0.000
Нейтральная: 0.000
Compound: 0.634
Метка: позитивный
```

### Пользовательские данные в интерактивном режиме

```bash
python -m sentiment_ru --interactive
```

Пример:

```text
Введите текст (exit для выхода): Это был великолепный день!
позитивный
Введите текст (exit для выхода): Фильм ужасный и скучный.
негативный
Введите текст (exit для выхода): Сегодня обычная погода.
нейтральный
```

### Анализ файла

```bash
python -m sentiment_ru --file examples/input.txt
```

Для CSV можно передать столбец:

```bash
python -m sentiment_ru --csv data/reviews2.csv --column "text"
```

## Формула итоговой оценки

Для каждого значимого токена вычисляется базовая лексическая оценка. Затем применяются модификаторы:

- отрицание уменьшает/меняет знак оценки;
- усилитель увеличивает модуль;
- ослабитель уменьшает модуль;
- `!!!` увеличивает эмоциональную интенсивность;
- CAPS усиливает оценку.

После суммирования вычисляются:

```text
positive = сумма положительных вкладов / нормирующий коэффициент
negative = сумма отрицательных вкладов / нормирующий коэффициент
neutral  = 1 - positive - negative
compound = нормализованная итоговая оценка [-1, 1]
```

Границы классов:

```text
compound >= 0.05  -> позитивный
compound <= -0.05 -> негативный
иначе             -> нейтральный
```
